# Pedro Vieira's Java Backend Portfolio

A terminal-style portfolio focused on Java backend development with Spring Boot and PostgreSQL. The site uses a scripted conversation to introduce my work, technical skills, and contact information.

[Visit the portfolio on Vercel](https://terminal-portfolio-chi-red.vercel.app/)

## Featured projects

- [Finora](https://github.com/pedro-vieiraf/finora) is a personal finance app that tracks accounts, transactions, and credit card bills and syncs Open Finance data through Pluggy.
- **Appointment System** is a REST API for managing appointments and sending email reminders.

## Site stack

The portfolio uses Next.js (App Router), React, TypeScript, Tailwind CSS, and SVG artwork. It supports dark and light themes. Page copy lives in `content/`, and project, skill, and contact data live in `app/data/`.
